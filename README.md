# Attention

This is a *public* repository.

## What belongs here

Organisation-wide defaults for CompisGmbH repositories:

- `.github/ISSUE_TEMPLATE/`: issue forms shown in every repository that has no issue templates
  of its own. A repository with its own templates shows none of these.
- `workflow-templates/`: templates offered under *Actions → New workflow* in every repository.

It is public because GitHub only applies default community health files from a public `.github`
repository. Only templates and defaults belong here: no configuration, no documentation of
internal setup, no scripts, no credentials, no customer or patient data. Change it through pull
requests.
